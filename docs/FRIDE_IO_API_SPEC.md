## 1. Overview & Prerequisites

Fride.io is a high-performance crypto and fiat payment gateway supporting cards, SBP (Система быстрых платежей), mobile commerce, and cryptocurrency assets (USDT, TRX, BTC, etc.).

### Account Requirements:
1. **Approved Merchant Account**: Create a merchant inside the Fride.io Cabinet, verify ownership, and pass moderation.
2. **Merchant ID (`merchant_id`)**: A unique UUID found in your Merchant Settings.
3. **API Key (`X-Api-Key`)**: Generated in the Personal Cabinet under API Keys. Must be generated by the **Merchant Owner** (employee keys do not have permission for merchant actions).
4. **Webhook Secret Key**: Single account-wide secret found in `API Keys > Configure Webhook & Secret` for validating incoming HMAC signatures.

---

## 2. Global API Headers & Authentication

All API calls must be directed to `https://api.fride.io`.

### Request Headers:
```http
Accept: application/json
Content-Type: application/json
X-Api-Key: {YOUR_FRIDE_API_KEY}
```

### Standard HTTP Status Codes:
- `200`: Success
- `400`: Validation error
- `401`: Unauthorized (Invalid or missing `X-Api-Key`)
- `403`: Forbidden (Key does not have sufficient permissions)
- `404`: Resource not found
- `429`: Rate limit exceeded
- `500`: Internal server error

## 3. Accepting Payments (Invoices / Orders)

### 3.1 Create Invoice (Создание заказа)
Initializes an invoice and returns the hosted payment link (`url`) where the customer must be redirected.

- **Endpoint**: `POST https://api.fride.io/invoice/create`
- **Headers**:
  ```http
  Accept: application/json
  Content-Type: application/json
  X-Api-Key: {YOUR_API_KEY}
  ```

#### Request Body (JSON):
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `merchant_id` | `string (UUID)` | **Yes** | Your merchant identifier from settings. |
| `order_id` | `string (1-100)` | **Yes** | Unique order ID in your system. Allowed characters: alphanumeric, `_-+[]\|=*@`. |
| `amount` | `number (float)` | **Yes** | Amount to charge. Decimal separator must be `.` (e.g., `10.50`). |
| `currency` | `string` | **Yes** | Currency code: `RUB`, `UAH`, `USD`, `EUR`. |
| `comment` | `string (1-512)` | No | Payment description shown to the buyer. |
| `expire` | `integer` | No | Lifetime in minutes (Min: 60, Max: 7200 [5 days]. Default: 360 [6 hours]). |
| `custom_fields` | `object` | No | Max 5 key-value pairs (key: 1-15 chars, val: 1-165 chars). |
| `service` | `string` | No | Payment method code to auto-select (e.g. `trx`, `sbp`). |
| `email` | `string` | No | Buyer's email for prefilling the checkout form. |
| `telegram_id_client` | `integer` | Conditional | Buyer's Telegram numeric ID (mandatory if merchant is linked to Telegram bots). |

#### Request Example:
```json
{
  "merchant_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "order_id": "ORD-2026-90412",
  "amount": 25.00,
  "currency": "USD",
  "comment": "Digital License Activation - Order #ORD-2026-90412",
  "email": "customer@example.com",
  "custom_fields": {
    "user_id": "1042",
    "product_slug": "algo-bot-pro"
  }
}
```

#### Success Response (`200 OK`):
```json
{
  "id": "8ef43261-2bfa-4c31-92b7-a37f59d4812b",
  "amount": 25.00,
  "currency": "USD",
  "url": "https://pay.fride.io/bill/8ef43261-2bfa-4c31-92b7-a37f59d4812b",
  "expired_at": "2026-09-17 20:48:30",
  "is_created": true
}
```

### 3.2 Get Invoice Info (Получение информации о заказе)
Fetches the current status and settlement details of an order.

- **Endpoint**: `GET https://api.fride.io/invoice/getInfo`
- **Headers**:
  ```http
  Accept: application/json
  X-Api-Key: {YOUR_API_KEY}
  ```
- **Query Parameters**:
  - `merchant_id` (*required*, UUID)
  - `invoice_id` (*optional if order_id is provided*, UUID)
  - `order_id` (*optional if invoice_id is provided*, string)

#### Success Response (`200 OK`):
```json
{
  "invoice_id": "8ef43261-2bfa-4c31-92b7-a37f59d4812b",
  "order_id": "ORD-2026-90412",
  "merchant_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "status": "success",
  "amount": 25.00,
  "currency": "USD",
  "credited": 24.25,
  "merchant_commission_amount": 0.75,
  "user_commission_amount": 0.00,
  "service": "trx",
  "custom_fields": {
    "user_id": "1042",
    "product_slug": "algo-bot-pro"
  },
  "created_at": "2026-09-17 14:48:30",
  "expired_at": "2026-09-17 20:48:30",
  "paid_at": "2026-09-17 14:52:10",
  "refund_at": null
}
```

#### Invoice Status Enum:
- `wait`: Awaiting customer payment.
- `success`: Payment completed successfully.
- `hold`: Payment received, funds temporarily on hold (treated as successful payment).
- `expired`: Order timed out without payment.
- `refund`: Order was refunded.

### 3.3 Customer Redirect to Merchant (Редирект покупателя)
When configured in the Merchant Cabinet, customers are redirected back to your website with query parameters after completing or failing a transaction.

> [!WARNING]
> Do NOT use this redirect URL alone to grant digital goods or credit balances, as client-side parameters can be manipulated. Always verify the signature or rely on the server-to-server Webhook!

#### Query Parameters Sent via GET:
- `invoice_id`: Operation ID in Fride.io (UUID).
- `order_id`: Order ID in your system.
- `amount`: Charged amount.
- `currency`: Currency code (`RUB`, `UAH`, `USD`, `EUR`).
- `merchant_id`: Your merchant UUID.
- `custom_fields`: Array/Object of custom fields passed during creation.
- `signature`: HMAC-SHA256 signature calculated from the parameters.

#### PHP Validation for Redirect Query:
```php
$secret = 'YOUR_WEBHOOK_SECRET_KEY';

$sign_parts = [
    $_GET['invoice_id'],
    $_GET['order_id'],
    $_GET['amount'],
    $_GET['currency'],
    $_GET['merchant_id']
];

if (!empty($_GET['custom_fields']) && is_array($_GET['custom_fields'])) {
    $custom_fields = $_GET['custom_fields'];
    ksort($custom_fields);
    foreach ($custom_fields as $value) {
        if (is_string($value)) {
            $sign_parts[] = $value;
        }
    }
}

$sign_string = implode(':', $sign_parts);
$calculated_sign = hash_hmac('sha256', $sign_string, $secret);

if (hash_equals($calculated_sign, $_GET['signature'] ?? '')) {
    // Verified user redirect
}
```

### 3.4 Invoice Webhook Notification (Webhook заказов)
Fride.io automatically sends an asynchronous POST HTTP request to your configured Webhook URL when an invoice status changes.

#### Webhook Request Headers:
```http
Content-Type: application/json
X-Signature: 0f2bc34c10cf28bf01c88a283e63ad0878dff1c19524ca55216b97c2273f4466
```

#### Webhook Payload (JSON):
```json
{
  "amount": "25.00",
  "credited": "24.25",
  "currency": "USD",
  "custom_fields": {
    "user_id": "1042"
  },
  "invoice_id": "8ef43261-2bfa-4c31-92b7-a37f59d4812b",
  "order_id": "ORD-2026-90412",
  "service": "trx",
  "status": "paid"
}
```
*Note: In the webhook payload, `paid` and `hold` both represent successful payment completion.*

#### Your Server Response:
Your server **MUST** respond with **HTTP Status 200 OK**. A response body is optional.

## 4. HMAC-SHA256 Webhook Signature Verification

To guarantee that webhooks are authentic and tamper-proof, verify the `X-Signature` header against the raw request body.

### Specification:
1. Parse incoming raw JSON body into an associative array.
2. Sort the array keys alphabetically (`ksort`).
3. Ensure `custom_fields` is treated as an object: `(object) $arr['custom_fields']`.
4. Re-encode the array to JSON with `JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES`.
5. Compute HMAC-SHA256 using your account **Webhook Secret Key**.
6. Compare with `hash_equals()`.

### Production PHP Helper Function:
```php
function verifyFrideSignature(string $rawBody, string $headerSignature, string $secretKey): bool
{
    $payload = json_decode($rawBody, true);
    if (!is_array($payload)) {
        return false;
    }

    ksort($payload);
    
    // Fix PHP associative empty array to JSON object conversion
    if (isset($payload['custom_fields'])) {
        $payload['custom_fields'] = (object) $payload['custom_fields'];
    }

    $sortedJson = json_encode($payload, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
    $computedSignature = hash_hmac('sha256', $sortedJson, $secretKey);

    return hash_equals($headerSignature, $computedSignature);
}
```

## 5. Payouts & Withdrawals (Выплаты)

Fride.io allows merchants to automate mass payouts to cards, bank accounts via SBP, mobile balances, and crypto wallets.

### 5.1 Get Account Balance
- **Endpoint**: `GET https://api.fride.io/user/getBalance`
- **Headers**:
  ```http
  Accept: application/json
  X-Api-Key: {YOUR_API_KEY}
  ```
- **Response Example**:
  ```json
  {
    "balance": 90738.73,
    "active_balance": 90738.73,
    "freeze_balance": 0.00
  }
  ```

---

### 5.2 Create Payout
- **Endpoint**: `POST https://api.fride.io/payoff/create`
- **Headers**:
  ```http
  Accept: application/json
  Content-Type: application/json
  X-Api-Key: {YOUR_API_KEY}
  ```

#### Request Parameters:
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `service` | `string` | **Yes** | Payout method code (from `/payoff/getServices`). |
| `wallet_to` | `string` | **Yes** | Card number, phone number, or crypto wallet. |
| `amount` | `number` | **Yes** | Amount in RUB (or method currency). Decimal with `.`. |
| `subtract` | `integer` | No | `1` = Deduct fee from account balance; `2` = Deduct fee from payout amount (Default: `2`). |
| `order_id` | `string (1-100)` | No | Payout reference ID in your system. |
| `webhook_url` | `string` | No | Custom webhook URL for status notifications. |
| `payoff_data` | `object` | Conditional | SBP bank code or mobile operator details. |

#### Request Example:
```json
{
  "service": "trx",
  "wallet_to": "TX1234567890abcdef...",
  "amount": 5000.00,
  "subtract": 2,
  "order_id": "PAYOFF-8841"
}
```

#### Response Example:
```json
{
  "id": "2fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

## 8. PHP Integration Architecture Blueprint

Below is the ready-to-use adapter service structure for our digital goods platform:

```php
<?php
namespace App\Services;

use App\Core\HttpClient;

class FrideService
{
    private string $apiKey;
    private string $merchantId;
    private string $webhookSecret;
    private string $baseUrl = 'https://api.fride.io';

    public function __construct(string $apiKey, string $merchantId, string $webhookSecret)
    {
        $this->apiKey = $apiKey;
        $this->merchantId = $merchantId;
        $this->webhookSecret = $webhookSecret;
    }

    public function createInvoice(string $orderNumber, float $amount, string $currency, string $email, string $description, array $customFields = []): ?array
    {
        $payload = [
            'merchant_id'   => $this->merchantId,
            'order_id'      => $orderNumber,
            'amount'        => (float) number_format($amount, 2, '.', ''),
            'currency'      => strtoupper($currency),
            'comment'       => substr($description, 0, 512),
            'email'         => $email,
            'custom_fields' => (object) $customFields
        ];

        $res = HttpClient::postJson("{$this->baseUrl}/invoice/create", $payload, [
            'X-Api-Key: ' . $this->apiKey
        ]);

        return ($res['status'] === 200 && !empty($res['body']['url'])) ? $res['body'] : null;
    }

    public function verifyWebhookSignature(string $rawBody, string $headerSignature): bool
    {
        $arr = json_decode($rawBody, true);
        if (!is_array($arr)) return false;

        ksort($arr);
        if (isset($arr['custom_fields'])) {
            $arr['custom_fields'] = (object) $arr['custom_fields'];
        }

        $sorted = json_encode($arr, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
        $expected = hash_hmac('sha256', $sorted, $this->webhookSecret);

        return hash_equals($headerSignature, $expected);
    }
}
```
